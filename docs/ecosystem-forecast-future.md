# 将来の予報UI（未実装）

天候基盤の接続状況は [v2天候基盤](ecosystem-v2-weather.md) を参照。予報操作UIは次段階。

Forestを入口にし、本体を停止してMainへ戻す。予報中は枠色を変え、時間controlsを終了ボタンへ置換し、手札の上に予報Viewを配置する。通常の配置/時間/日照操作から本体状態を変更しない。

バーの上中央に予報日時。降水量バーは0を黒、黒枠、赤い現在位置。クリックでscrubできる。下段は大/小巻戻、再生1x・2x・4x・10x、小/大早送。

盤面では雨の位置と濃さで強度を表示。予報用の時間だけを動かし、本体時間・水分・植物を不変に保つ。入る前の本体スナップショットと一致することを検証し、終了後も停止を維持する。予報を本体へ適用する操作は今回の仕様に含めない。

この文書は要件記録のみ。今回の根/戦闘接続では予報・季節・天候生成を実装しない。
