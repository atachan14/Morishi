# 手札に入る時点で能力を確定する・2026-10-11

ユーザー1791719383.474599「それでおっけい！」により、親の提案「手札に入る時点で能力確定、既存の手札と配置済み植物は変えない」が承認された。

## 今回の動作

敵を倒す → 敵の能力構成から分類 → player倍率を強化 → 以降、手札に入る植物へその倍率を適用して確定 → 配置時は札の確定値をそのまま使う。

既存手札、配置済み個体、初期味方へplayer倍率を遡及しない。個体の成長・射程/存在感半径の成長補正は従来通り続く。配置時や再読込時に最新倍率で再計算しない。

比較用の暫定調整は、敵の `dominant(stats)` 分類に対応する倍率へ撃破ごとに＋0.01。攻撃型→攻撃、射程型→射程、存在感距離型→存在感半径、生命型→最大HP。初期は各1.00、同分類を2体倒すと1.02。加算するのは能力そのものではなく乗算係数。種族を先に選んで能力を生成する方式へ戻していない。

強化量、分類と強化先の対応、累積方式は未合意のゲーム性判断なので、最終値と扱わない。UIに「比較用」「暫定」を表示する。現ステージは初期敵24体なので最大でも1.24となるが、別のゲーム性上限を新設したわけではない。調整値や分類式を変更するときはpolicy/保存版を更新し、旧保存を新しい算式で解釈し直さない。

## 保存するもの

- `PlayerProgress`: policy `hand-entry-v1`、現在の4倍率、撃破した敵IDとtickの履歴。
- `SeedCard.baseStats`: 札として確定した能力。`snapshot`には生成方式 `composition-v1`、倍率適用前の能力、適用倍率、手札入りtick、参照した撃破IDを保存。
- 配置済み個体の `seedSnapshot`: 消費した札のsnapshotを値としてコピー。基礎能力・HPと成長中の倍率を分離して保持する。
- 再開では生成IDとseedから元能力を確認し、手札入り時点の撃破と保存された倍率・確定能力を照合する。現在のplayer倍率を札へ再適用しない。

強化付き比較runはsnapshot-8。既存snapshot-7は能力・進行・手札をそのまま復元し、過去の撃破から強化を遡及計算しない。既存snapshot-3〜6も維持する。旧runを強化版へ勝手に変えず、新しい「遊び比較」を明示開始すると旧保存を退避する。旧ルールの保存runにはその旨を表示する。不明/不正保存を自動上書きしない。

## 意図した短い例

射程型の敵を撃破してplayer射程倍率が1.01へ上がる。手元の4枚は変わらない。そのうちの旧札を配置しても旧能力のまま。一方、その配置によって補充される次の札は元射程×1.01で確定し、以降player倍率が増えてもその札の射程は書き換わらない。配置した植物はその確定射程を基礎に、従来の成長補正を受ける。

現在は即時補充なので「次に手札へ入る」は配置成功による補充時点。DrowHeist/TurnHeist・手札満杯時の時計・合体は今回実装していない。

## 属性の相談との関係

属性数・属性ベクトル・相性式は未承認。今回は属性値、粒子、状態異常、属性による一般能力倍率を追加していない。生成前の能力と適用倍率の記録を分離し、生成方式に版を付けているため、将来の属性情報は新しい生成方式/保存版で明示的に追加できる。通常能力の4倍率と属性を勝手に同一視しない。
