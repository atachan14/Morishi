# 選択Plantの根・栄養情報

730f599の出生表示に続き、既存のPlant詳細の中に、通常は閉じた「根・栄養」を追加した。MainPaneに説明や新規パネルは置かず、選択属性のPower/Resist/Range/Speedだけを表示する。既定の成長・雨・合体・栄養値は変更しない。

## 表示の意味

「条件」は現在の昼/夜、敵接触/合体待ち、貯水0。未配置と最初の根tick前の配置も区別する。貯水0だけで次tickの水不足停止を断定しない。次の吸水を表示のために実行しない。

「直前」は最後に実処理が受け取った水量と消費量/本来の成長消費量（毎シミュレーション秒）。実際のgrowthAllowedとgrowthConsumedから水制限、growthWishとの差から接触制限を表示する。夜の消費要求0で水制限とは断定せず、「条件 夜・敵接触・貯水0」と「直前 夜」を同時に扱える。環境ボタンで昼夜を変えても、直前の履歴を現在値に書き換えない。

表は現在値への即時加算ではなく、栄養を消費した場合の能力増分。すべて実処理と同じgainsを一度だけ掛ける。

- 直前受入: 直前の1tickで実際に受け取った通常mixと追加bonusの換算量。毎秒表示ではない。既にそのtickで一部消費されている場合もある。
- 通常保管: 現在のmix×gains。
- 追加保管: 現在のbonus×gains。死体や既存土壌bonusを含むため、出所を死体だけと断定しない。
- 周辺死体: 根と死体が土壌の同じサンプル点を覆う場合のremaining×gains。在庫の配分前で、この個体の確定取り分ではない。満水や競合などで受入0でも残量はある。

周辺の「枠%」はwaterRemaining/initialWaterで、回収の残り枠。在庫の能力増分%とは同じではない。ゼロは—、正の微量は+<0.001とし、微量をゼロに見せない。

## 実処理からの取得と保存

rootGrowthLimitを成長処理と現在条件の表示で共有し、同じ表面間距離・系譜条件・消費予算を読む。実処理が集計済みのcomposition/bonus受入を診断へ返し、追加の成長・吸水処理は行わない。

直前測定はRootGameRuntimeをキーとするWeakMapに保存外で保持する。生存個体ID、tick、測定時のlineageを確認する。測定後の合体では古い個体の測定を流用せず未計測に戻る。保存復元では現在在庫と条件をそのまま読めるが、直前測定は未計測。次の実tickで更新する。表示だけで履歴を作らない。新schemaや保存データの必須項目は追加しない。
