# 間隔を空けた非均等な小集団の仮採用

## 採用した生成

新規runは `spaced-pockets-v1`。四つの群の拠点・24体・基礎seed・手札・成長速度・合体・戦闘ルールを残し、群内の周辺個体を約1.1〜1.4倍の距離へ非均等に広げる。各群の最初の二体は従来の近さを残す。群全体の場所を全面的にランダム化した変更ではない。

一律1.25倍では今回の3seedで敵合体0/0/1回、一律1.5倍では全て0回だった。広くするだけでは「成長してぎゅうぎゅうになり合体」を失う。近い小集団を残す候補は同じ配置方針の600秒試験で敵合体2/3/4回を残し、敵撃破個体は従来11/5/5から17/7/7へ増えた。そのため、この小集団案を仮採用した。

画面・比較選択肢は増やしていない。現在runの配置の説明だけを追加。既存runは座標・計算・手札を保存から維持し、「同じ条件で最初から」も旧生成を使う。新しいrunを明示開始すると新生成を使い、直前のrunは従来どおり退避する。

`State.enemyLayout` は省略時に従来生成、値が `spaced-pockets-v1` のとき新生成。未知値は保存を保護して拒否。ユニットの計算や手札生成に配置タグは混ぜない。新旧で同じseed・カード番号のraw能力と属性役割対応は同一。獲得報酬が違う場合、その後に入る手札の倍率は実際の進行に従って異なる。

## 同じ手札から配置を変えて勝利まで追う

射程倍率2、seed11・77・20261011で同じ初期三枚を第一の味方の後ろへ置いた。後続は弱い敵へ前線を移し、育成候補があれば射程の長い手札を選ぶ。単独で届かなければ射程外に育成拠点を作り、近くに手札を置いて合体の射程・火力・耐久を足す。敵がまだ成長・合体する場合、拠点が後で危険になることもある。

これは精密な自動配置方針による経路の確認で、初心者が同じ速さで勝つことの証明ではない。最初の三枚を中心距離8.1で置く試験に加え、20の余裕を取る試験も行った。以後の接触支援は依然正確な座標であり、実際のテストプレイで配置の読みやすさを確認する必要がある。

|seed|25%吸収＋近い標的:旧→新の勝利ゲーム秒|新の味方死亡|新の最初の敵合体|敵合体後に作った前線|
|---|---|---:|---:|---:|
|11|544.1→368.9|3|54.1秒|7|

最初の味方の発射は新旧とも0.5秒、最初の敵撃破は2〜3秒。新生成で直径200の味方が初めて現れるのは61.3秒。初期三枚の合体は0.1秒だが、別に敵が成長して接触・合体する過程も起きる。合体後でも単独育成・合体拠点による新苗の復帰と24元敵ID全ての撃破を確認した。

標準の100%吸収＋ID標的でも同じ方針を試した。新生成は91.6 / 93.4 / 86.7秒で全滅勝利、最初の発射0.3秒。旧生成は122.1 / 135.8秒で勝利し、seed20261011では600秒・16体撃破で方針が停滞した。後者はこの探索方針の限界であり、ゲームとして勝てないという証明ではない。

標準100%では先に倒してしまい、seed11の敵合体は0回。32seedで味方を除いた自然成長診断では全seedで敵合体が起きた。合体は可能な配置だが、プレイヤーが先制すると阻止できる。100%吸収の雪だるま式の強さは残っており、25%吸収は育成・合体の過程を観察しやすい。今回、戦闘の標準値を変更してはいない。

20の余裕で置く初期配置でも、新生成3seedは25%吸収と標準100%の両方で勝利した。最初の発射は0.7〜1.0秒へ遅れた。初期三枚の厳密な接触即合体だけに依存した経路ではない。ただし、その後の支援位置は自動配置なので、人間の操作許容幅は未検証。

## 安全な場所と陣地の広がり

固定32×24＝768点の幾何診断で、初期の置ける点は旧765〜766、新766。現在の敵射程外の点は旧711〜721、新709〜717。新生成が盤面全体を一律に安全にした結果ではない。群内で敵が大きくまとまりにくく、倒す相手や前線を選べる余地を作った効果が中心。

自然成長では身体・存在感・射程が広がり、空きが減る。新生成25%試験の最小の置ける点は683 / 688 / 687。その後、敵撃破で再び空く。seed11では60秒の683点から120秒709点、180秒718点へ増えた。味方も育って場所を占めるため、敵がいなくなっても全点が新苗用の空きになるわけではない。

これは格子点の数であり厳密面積ではない。診断時は手札・配置力と終了状態を除いて身体・存在感だけを検査している。勝利後に実際に置けると主張する値ではない。現在の射程外も未来の成長・合体に対する安全の保証ではない。

## 待機中の介入と朝に確認すること

手札の長い射程を読む、攻める敵を変える、射程外に拠点を作る、受け手の属性対応を見て合体で射程や火力を足す、という介入で勝利へつながった。新生成25%試験の味方無発射の最長は68.8 / 29.8 / 1.0秒。無発射を完全には消していない。

育成候補が出ない手札を近い合法点へ置くだけでは即死することがある。特に「一枚では届かず、合体で射程を足す拠点」は現UIが自動提示しない場合がある。今回の経路はその場所を数値で探しており、初心者が自然に思いつけるかは残課題。25%で最も長い68.8秒の待機が、育つ意味を感じる時間か退屈かも未確定。

朝はseed11で新しいrunを作り、既存の25%吸収設定で、近い敵二体の成長合体を見られるか・合体後に別の敵へ前線を作れるか・短射程の札を支援へ使いたくなるかを確認するとよい。新しい比較設定を増やす段階ではない。

## 未使用seedでの確認（103・509・811）

### 停滞の切り分け：別前線で復帰できるか

元の600秒記録を残したまま、コピーで探索先を一度だけリセット。近傍の半径候補だけを探し直す継続では、509の新旧・811新はいずれも1200秒まで配置も攻撃も増えなかった（`holdout-renewed`）。

同じ600秒地点から、局所候補がなければ盤面全体の768格子点を調べ、現在の敵射程外かつ配置可能な地点で弱い敵に近い場所へ新しい芽を置く診断を追加。戦闘・乱数・手札・配置費用は同じ。509旧742.7秒／新697.8秒、811新730.7秒で全24由来を倒して勝利。初期からの全配置座標再生・最終保存一致。朝の自動候補機能への採用はしていない。

したがって600秒での停滞は、配置できない盤面の証明ではなく、局所の支援先へ固定した探索方針の限界。世界全体の安全な場所へ新しい前線を作り、追加の手札で合体支援する既存の遊びによる復帰経路がある。ただし600秒地点から始めたため、最長の攻撃空白は約582〜594秒を含み、体感の待ち時間は未解決。過適合がないことを一般的に証明したわけではない。
