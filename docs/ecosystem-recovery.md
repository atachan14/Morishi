# 成熟した敵に対する配置の立て直し

## 今回採用した小さな改善

同じ手札で「合法な場所」と「育って攻撃へつながる候補」は違う。候補ボタンは、まず手札の最終射程と敵の射程・身体を考慮した育成候補を探すようにした。見つからなければ従来の合法地点を提示し、育成候補は今回の有限探索では未確認だと明示する。手札を勝手に交換せず、植物や配置力も消費しない。標準の成長・耐久・存在感・初期敵配置・保存形式は維持した。

敵8体まで、各16方向×2距離、最大256点。敵同士が今後成長で接触・合体し得る局面は未確定として育成候補を提示しない。敵が合体せず自然上限まで育つ仮定で、敵射程の2倍より外側かつ直径200の芽が身体に接触しない地点を探す。そこで手札が直径200まで育つと敵に届く候補を比較する。最大直径は実際の成長が続いた場合の仮定。今後の敵合体・標的変化・別の配置は未予測であり、安全や勝利の保証ではない。有限探索の不発は配置不可能の証明でもない。

候補メッセージには、接触しなければ攻撃圏へ入るまでのゲーム秒を表示する。危険な地点の予測には、現在の全被弾の一発ダメージ×攻撃速度の合計と初期HPを表示する。攻撃時計や標的が変わるため、HP÷被弾を生存時間として保証しない。

## 原因と具体例

seed 11・77・20261011、集中開始の既存配置履歴を240ゲーム秒まで再生した。従来の探索は最初の敵の存在感半径×1.3付近の合法点を先に選ぶ。存在感1.5以下は植えられる条件であって、敵射程外の条件ではない。

|seed|従来候補の初期HP|現在の被弾目安/秒|実際に倒れたゲーム秒|同じ手札の育成候補が最初に撃つ秒|
|---|---:|---:|---:|---:|
|11|150.8|344.9|0.4|34.6|
|77|127.0|258.6|0.5|49.3|
|20261011|113.3|179.8|0.7|54.3|

育成候補は三条件とも単独配置の70ゲーム秒で生存、直径200に到達し、実際に発射した。保存再生も一致。これは完勝や連続戦闘の保証ではない。18枚の手札を別々の世界で比較すると、育成候補が見つかったのは4 / 3 / 2枚。残りは射程が短い等で未確認。seed 11では最初の強い敵だけを見ると単独で育って射程に届く点は見つからなかったが、別の敵#16なら手札#43・#45・#46・#48に育成候補があった。短い射程の札は前衛への合体や支援を考える余地が残る。

例: seed 11の敵#10は直径323.3、HP1798.9、射程半径291.0。敵#16は直径200、HP406.5、射程91.4。同じ芽を常に#10へ向けることが停滞を悪化させる。芽の自然上限・射程だけでは強い合体敵の攻撃圏を越えられない場合がある。合体して射程や耐久を足す経路と、別の弱い敵から攻める経路は分けて考えるべき。

## 既存パラメータを変えた有限比較

アプリ設定は増やさず、検証スクリプト内だけで候補を比較した。240秒時点から各候補を70秒進める基礎耐久2倍（既存個体は傷の割合を保って換算）・味方成長6・両軍成長6・存在感閾値1.0の比較では、生存・発射できる候補数は標準と変わらなかった。成長6は届くまでの時間を半分にするが、危険な位置や届かない射程を解決しない。存在感を厳しくすると危険な合法点は減るが、育成可能な点が増えるわけではない。

初期状態から同じ配置方針で600ゲーム秒進めた比較:

|seed|標準:最長発射なし秒 / 撃破個体|両軍成長6|敵間隔1.1倍|敵間隔1.25倍|
|---|---|---|---|---|
|11|183.5 / 11|188.6 / 8|177.8 / 11|139.8 / 17|
|77|184.8 / 5|211.3 / 5|178.7 / 5|147.8 / 7|
|20261011|185.2 / 5|221.9 / 4|179.8 / 5|58.2 / 6|

間隔1.25倍は有望だが、敵の合体構成と前線の難しさも変える。合体と前衛の価値が変わる検討を残すため、今回の小さな修正では採用せず、選択肢を増やさず比較結果を残した。耐久倍増や一律成長加速より、まず役割・射程を読んで攻める相手と地点を変える導線を改善する判断。

## 配置方針全体の確認

同じルールで600秒進め、240秒以降の前線拡張に育成候補と届きやすい手札選択を使った。手札一枚の独立試験とは別の、選択方針を含む比較。

|seed|味方の発射:従来→育成候補|倒れた味方|敵個体撃破|味方の最長発射なし秒|
|---|---|---|---|---|
|11|386→560|37→20|11→13|455.2→219.9|
|77|138→561|37→17|5→9|545.0→209.1|
|20261011|125→358|37→16|5→8|545.3→216.0|

合体数も62/59/59から79/81/80へ増え、前衛へ接触させる配置を残したまま味方の戦闘と撃破が増えた。全9方針試験の最終保存は厳密再生一致、全てまだプレイ中。配置数や時間を勝利の証明として扱わない。

従来の最長183〜185秒は両陣営の発射を数えた値。敵が新しい芽を撃つだけでも区間が切れる。今回、味方だけの発射を別に集計したことで、攻撃が止まる課題がさらに大きいことが分かった。また、従来スクリプトは最初の240秒を同じ方面への接触配置に固定していた。185秒はゲームが強制する待機時間ではなく、この配置方針の影響を含む。

育成候補に変えると両陣営の最長発射なしは195.6/208.8/215.8秒へ増えた。芽が直ちに倒れる代わりに育つ準備時間を取るためで、改善は即死の減少・味方発射・撃破に現れる。戦闘のない時間自体を消したわけではない。

10秒の無発射から早く前線を作る方針も比較した。両陣営の無発射は約50〜57秒に短くなったが、倒れた味方は40/38/42体で、240秒から立て直す場合より多い。合体中の未確定判定を入れても、合法点への配置や後の敵変化による損失は残る。序盤から常にこの方針を自動適用する案は採用しない。候補は観察と手札選択の補助として使う。

証跡: `scripts/ecosystem-recovery-strategy.mjs` と各seedの `*-strategy.json`。指標は味方・敵の発射を区別し、末尾の未発射区間も含めた。

## プレイヤー強化と新しい手札

240秒時点の属性倍率はseed 11で1.01〜1.04、他二条件で1.00〜1.02。倒した個体一体につき主属性+0.01で、合体敵でも元敵ID数だけ加算するわけではない。HPの基礎値もこの属性倍率では増えない。既に手札へ入った種は固定され、後の報酬では強くならない。手札が6枚で埋まればドロー時計は止まり、待つだけで手札が入れ替わることもない。

したがって、現在の強化だけで成熟敵との差が自然に埋まるとは言えない。新札の属性と役割の対応、射程の長い札、合体で足す能力を読む必要がある。今回の候補改善で無駄な即死を減らす入口はできたが、長い準備・勝利までの回復経路・報酬の実感は朝の遊びの残課題。
