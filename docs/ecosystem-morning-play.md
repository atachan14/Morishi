# 朝の短い比較試遊

入口：`http://127.0.0.1:8781/ecosystem.html`。比較は新しい庭を作るため、今の比較runは前runキーへ退避する。旧ページのrunは別の保存。

1. 「敵・観察」→「新しい庭の比較設定」を開き、seed **11**、局所射程、**全能力25%**で新しい庭を始める。
2. 最初の敵#1の左上へ芽#2を前衛として置く。敵から左60・上45が記録の配置。芽#3をさらに左60、芽#1をその下90へ。厳密な数値入力はないので、最初は概形の比較でよい。
3. 追加の札を置かず、ゲーム内表示が約10秒になるまで進めて止める。敵#1の「標的を確認」と、前衛・後ろの味方のHPを見る。スマホは札を選んだ後、詳細の「この植物を置く」で庭に戻る。
4. 同seed・同射程の **全能力25%＋同じ存在感なら近い相手**で新しい庭を作り、同じ配置を試す。前衛が狙われるか、後ろが射撃できるか、近い前衛の被弾が増えるかを比べる。
5. 続けるなら20〜30秒へ。触れて吸収した後に、詳細が受け手へ移ることと、独立した後衛が残る距離を確かめる。見失ったら「全体」→個体／「味方へ」。配置待ちでもdragやpinchは移動・拡大で、指を離すだけでは植えない。

停止中の配置・詳細確認でよい。終えるときは「今回の観察を終了」。ページを閉じても保存した庭は停止状態で再開する。

朝に返してほしいのは **「狙われる相手が予測できたか」「前衛へ置くカードを選ぶ意味があったか」「もう一度配置を試したくなったか」** の3点だけ。厳密な自動比較の座標・数値は [標的比較](ecosystem-targets.md)、技術的な確認と未検証範囲は [長期安定性](ecosystem-long-stability.md) にある。

途中で「試遊の再開 → この地点を残す」を押すと、同条件で最初から試しても「残した地点に戻る」で停止中の盤面に戻れる（手動一点のみ）。合法候補を探したら手札詳細の「この候補での攻撃・被弾」を確認。置けなかった場合は拒否理由の詳細で接触IDと敵の寄与を確認する。詳しい再現条件と限界は [配置を続ける検証](ecosystem-active-trial.md)。

成熟した敵に新しい芽がすぐ倒れる場合は、射程の長い札を選んで「手札の候補を探す」。育てる候補なら接触なしで攻撃へ届く目安が表示される。待つ間も別の札で支援できる。未確認と出た札は、前衛への合体や別の敵への支援も比べる。「安全」や勝利の保証ではない。朝は、候補の説明で即死を避けられるか・育つ待ち時間が長すぎないか・短射程の札にも使い道があるかを追加で観察するとよい。詳しくは [成熟敵への立て直し](ecosystem-recovery.md)。
