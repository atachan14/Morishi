# 根と戦闘・表示UIの接続

URL: http://localhost:8781/ecosystem-v2.html 。Settingの根成長ONで新規作成。根runは引き続き保存なし、旧保存と通常モードは保持。独立比較ページroot-trial.htmlも継続。

本体UnitのHP/直接Stats/サイズ/生存IDを根へ渡してから吸水成長し、HPRegを一度適用して戦闘・治癒を集計。被ダメージ・治癒・死亡処理後に根へ同期する。死者は根参加者から除外し、次tickで吸水しない。死者の残り貯水/有限bonusはretiredWater/retiredBonusに保持し、土壌への死亡栄養投入はまだ行わない。勝利後は根も停止。サイズStatsの再乗算なし。根モードの防御係数は確定案100/(100+Defense)、旧runは既存式を維持。

敵との外周接触でサイズを増やせない間は能力成長も停止。成長用の水は消費しないが、吸水と容量までの貯水は続く。間隔が残るときは双方の最大成長分を見た保守的な水消費上限で重なりを防ぐ。合体の根面積/容量が未決のため、根モードは合体をしない。同陣営接触も成長保護し、個体に「合体未決：成長保護」を表示。能力合算などのルールを独断で確定しない。

時間行のボタン以外/右端印で表示を開閉。時間ボタンや表示ボタン操作は開閉へ伝播しない。6行: 既存5トグル、水分/HP/Reg/根/存在感、炎・氷・電・闇それぞれPower/Resist/Tech/Range/Speed。根と水分は対応する円/土壌表示、数値は選択個体（未選択なら画面中心に近い個体）の盤面ラベル。データは現在の実効値。Techniqueは未定義なので無効ボタンで明示。Rootのない通常runでは水分/根を無効にする。

Plant基礎はHPバー（Max/HPRegも保持）、サイズ｜水分、存在感｜根。吸水/接触停止状態を下に表示。各属性の防御はResistとして属性タブへ移し、Power/Technique/Range/Speedとともに保持する。

検証:267 tests、typecheck/build成功。根専用回帰で被ダメージ維持、HPReg一度、治癒保持、死者除外/勝利、接触時の能力/サイズ/水消費停止、吸水継続、合体保護。Rootの小数MaxHPを戦闘後の丸めで超えないよう補正。隔離Edge1366×900/390×844/320×568で6行、開閉伝播防止、実攻撃2〜3イベント継続、複数tickのHP同期、基本/属性表示、旧primary JSON不変を確認。エラー0。実機スマホではない。
