# 長期の技術的安定性・見やすさ：2026-10-11

## 結果と修正

朝の比較候補は3つのまま。ゲームの成長・吸収・属性対応・標的比較の数値は変更せず、次を修正した。

1. **長いrun→新runの定期保存**：前runの `lastSaved` が残るため、tick0から始めた新runの定期保存が前runのtickまで遅れていた。保存成功時に現在のtickへ基準を更新。300秒のrunから新runを作り、手動停止前にtick50が保存されることをPC/スマホで確認。
2. **吸収で消えた選択ID**：左右詳細は消えたIDのまま空になっていた。生存個体の系譜から受け手へ選択を追従。死亡して系譜を持つ受け手がなければ解除する。手札を選択中は手札詳細を優先し、吸収で上書きしない。
3. **停止中の弾VFX**：直近5ゲームtickを条件に、実時間の剰余で弾を描いていたため、停止すると弾が繰り返し動いた。弾一発の表示を300msの実時間にし、同じshotは再生しない。画面外のshotも時刻を同期し、カメラ移動で古い弾を再生しない。保存のshotは履歴として扱い、再開時は再生しない。
4. **ID保存上限の不整合**：手札生成上限100万に対し `nextId` の保存上限も100万で、初期27個体分だけ早く拒否される。`nextId` の範囲を生成上限＋28へ合わせた。上限を越えるデータは引き続き拒否。100万枚を実際に置いた試験ではなく境界値テスト。

VFXの記録は生存個体ごとに最大1件、消えたIDは除去。イベントは既存の最新8件、DOMログも最大8項目。弾やログの無制限な蓄積はない。スキルカード・新しい戦闘条件は追加していない。

## ゲーム時間を進めた試験

`scripts/ecosystem-long-stability.mjs` は通常生成seed11を使い、実際に `stepEco` を呼ぶ加速シミュレーション。1時間の実時間放置や24時間のbrowser soakではない。

|条件|実際に進めたtick|ゲーム時間|CPU時間|保存再開照合|
|---|---:|---:|---:|---:|
|100%継承・ID同値|6,000|10分|約0.99秒|6回|
|25%継承・ID同値|6,000|10分|約1.00秒|6回|
|25%継承・距離同値|36,000|1時間|約5.07秒|36回|

全保存で状態の完全一致。HP・直径・年齢は有限、最大HP超過なし。終盤は各8個体、自然成長後の最大直径約384.2、ログ8件、手札6枚、配置力5、満杯時計の端数も維持。通常生成の保存は最大約12.8KB。試験全体はsyntheticの短い保存測定も含め約7.4秒のCPU時間で終了。

初期味方全滅後の成熟した敵と満杯資源の待機が時間の大部分を占める。UIはこの状態で自動停止する。高密度の活動戦闘を1ゲーム時間続けた試験ではない。

追加の単体テストは、成熟した状態のtickを4,000,000へ設定して1,000tick進め、年齢・満杯時計・保存の大きい数値を確認する。これは数値境界fixtureであり、111時間を実際に進めた結果ではない。手札生成上限のテストも同様に人工的な境界値。

## 大きい身体・高密度の境界fixture

`scripts/ecosystem-stress-fixtures.mjs` は次の人工盤面を作る。属性・基礎seedは生成器から作り、保存の形・系譜・敵24体の由来を検証するが、自然にプレイして到達した記録ではない。

- 巨大：55体の同陣営を面積保存で吸収し、直径1483.24の味方と敵8体。保存約13KB。
- 密度：味方104体＋敵24体、直径200の128体上限。保存約114KB。通常の合法配置履歴を再現した盤面ではなく、描画と保存の上限確認用。動かすと敵が合体し、12tick後は111体。
- 吸収直前：味方#26→#25、敵#2→#1が次tickで起こる盤面。左右詳細・手札優先の操作確認用。

各fixtureで12回の保存・読込一致と短いstepを測定。密度fixtureの保存書込は最大約9.4ms、読込約6.0ms、step約5.6ms（最初の合体処理を含む）。100万手札の履歴再生や重い長時間試験は行っていない。

## 描画・選択・存在感・カメラ

- 巨大身体は実直径のまま描く。「味方へ」で全身がcanvas短辺の約80%内に収まる拡大率へ調整。巨大身体の中心から半径の80%離れた部分を実入力で選べることを確認。全体表示との往復とviewの保存再開も一致。
- 存在感描画は全観測で有限の半径、外側は内側の正確な2倍。PC/スマホで巨大と密度とも無効gradient 0。
- 数値テストでは直径1000の敵について、存在感半径内は2、1.25倍で1.5、2倍以遠で0を確認。1.25倍では配置可、1.24倍では不可。実身体の半径・存在感半径・攻撃射程を同じ境界と扱わない。
- 色の薄い存在感表示は場所を見る補助で、敵合計1.5の厳密な等高線ではない。配置候補のメッセージは実際の判定と敵合計を使う。選択中の長い破線は減衰前の射程半径。攻撃限界はその2倍。
- 巨大と密度の画像は目視確認。スマホの手札は初期画面内。個体一覧・詳細の縦スクロールと手札横スクロールを分け、横溢れなし。
