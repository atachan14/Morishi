# 盤面の広げ方を変える小調整

2026-10-11。基準コミット: 86dcfa7。

## 狙い

新seedでも敵の座標が同じだったため、入口と進む方向が似通っていた。能力値や供給を同時に変えず、全敵初期配置のまま座標だけ少し変え、上側/下側・中継位置の選び方を変える。ユーザー確認済みのseed 20261011は基準盤面として元の配置を保持する。

新seedの座標は連続値。7つの疎な配置の骨格から、左右±0.35・上下±0.7と上下反転で変化させる。座標生成は能力生成と別のseed由来乱数列を使い、今回の比較で能力差を混ぜない。生成後の乱数、追加敵、対人風CPU、隠れた敵は追加しない。敵は全て最初から見える。

## 比較

`npm test`後に `node scripts/balance.mjs --reference` と `node scripts/balance.mjs`。同じ13seed・3配置方針・2400tick上限で比較。最初のseed以外の新配置だけを変更した。自動配置の探索候補は検証用であり、ユーザーの自由配置を量子化しない。

| 配置方針 | 固定配置の勝利 | 新版の勝利 | 平均tick 固定→新版 |
| --- | ---: | ---: | ---: |
| 前線優先 | 12/13 | 12/13 | 667→580 |
| 最初に1体置き40秒待機後に前線 | 12/13 | 12/13 | 814→924 |
| 後方優先 | 0/13 | 0/13 | 1292→1439 |

前線に置く方針の攻略性を保ち、後方へ固める方針の攻略は改善しない。人間の面白さや統計的な優劣を証明するものではない。新版の後方配置で2run（seed2/9）は上限時点でも微弱な攻撃が続いており、数学的な停滞として強制終了しない。これを勝手に敗北にせず、自分で「今回を終える」導線を追加した。詳細は `evidence/map-reference.json` と `evidence/map-generated.json`。

## 領域の手応え

- 配置前に新しく広げられる周辺を淡い点で示す。表示用サンプリングであり配置判定ではない。
- 配置・敵攻略で領域を得た時に短い波紋を描く。シミュレーションを変えない表示効果で、停止中にも余韻は消える。
- 「今回を終える」はそのrunの領域と攻略数を保持した結果画面へ進む。永続セーブではない。同seed再挑戦・新seed開始は別々。
- 自由座標、重なり/境界プレビュー、射程/存在感/距離減衰、固定tick・pause/速度、PC3Pane/mobile1Paneを維持する。
