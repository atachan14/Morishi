# 配置比較と継続の試遊記録

2026-10-11、`diameter-linear-1`。本人就寝中の自律継続。能力対応／実直径／手札固定は維持し、仮バランス値はこの比較では変更していない。

## 何を変えて遊んだか

seed11／77／20261011で、開始時の同じ札#1〜#3を3枚追加。配置力3を使い、90ゲーム秒まで追加しない。同seed内で能力対応、初期敵、初期味方は同一。比較は次の3通り。

- **一群への密集支援**：最初の敵から左70・上下38の二箇所、左150の一箇所。既存の味方1体を三枚で助ける。
- **三群への分散支援**：初期味方3体のそれぞれ55左へ1枚ずつ。別々の攻防に支援を分ける。
- **中央の遠方配置**：(2048,1536)、(2100,1536)、(2048,1588)。敵群から離し、三体の成長と接触合体に賭ける。

| seed | 密集：30秒 / 90秒の撃破 | 分散：30秒 / 90秒の撃破 | 遠方：30秒 / 90秒の撃破 |
|---|---:|---:|---:|
| 11 | 3 / 3 | 7 / 7 | 3 / 5 |
| 77 | 3 / 3 | 3 / 3 | 1 / 1 |
| 20261011 | 4 / 4 | 3 / 3 | 1 / 2 |

seed11は一群への過剰集中より、各群に1枚ずつ足した方が30秒までに多く攻略した。seed20261011は逆に最初の群を集中して崩す方が少し進んだ。能力対応を含む個体差で、同じ配置方針の価値が変わる。

中央の三枚は30秒までに2回吸収合体した。遠くに置いても、合体ボーナスと成長で射程が伸び、後から敵群を攻撃する。そのため「離れた場所ならずっと戦闘が起きない」とは言えない。seed11では30秒後も撃破が増えたが、他のseedでは進みが遅かった。

全9試行とも90秒まで追加をしないと味方が消えた。これは「負けたら終わり」を確認した記録ではなく、3枚だけで敵24体を一掃できる調整になっていないことと、**全滅後に残った札を再配置する案内が必要**なことを示す。勝率や最良戦略の断定には使わない。

生データ：[placement-comparison.json](../evidence/ecosystem/placement-comparison.json)。tick40／100／300／900のHP、直径、射程、残数、合体回数と正確な配置座標・札対応を収録。再生成は `npm test` 後に `node scripts/ecosystem-placement-comparison.mjs`。

## 継続と配置不能の扱い

- 味方0でも、手札・配置力と合法な場所があれば継続。seed20261011で自然全滅後に再配置し、固定札のまま保存／復元して同じ進行になることをテスト。
- 場所探索は合法な点を示すか、矩形全体が身体・敵存在感に覆われることを下限／上限で証明する。粗いグリッドで点が見つからないだけでは配置不能にしない。4096矩形／深さ24の上限で、判断できない場合は「未特定」とする。
- 全域の敵存在感・巨大身体・個体数上限は人工的なストレス条件でも検査。空きが増える戦闘／合体があり得る場合は観察可能とする。そうでなければ待つだけでは回復しないと案内し、時間を止める。自動敗北や旧run変換はしない。
- 自然生成の敵24体は、敵由来数kについて直径が約`200√k`以下。halo≤4なら存在感の外周円の面積合計は約739万以下で、盤面約1258万より小さい。全味方消滅時に敵だけで全域を覆うことは現行の成長／合体制約では起きない。6seedの成長後も合法な点が残ることをテストした。味方の巨大身体や個体数上限は別の制約。
- 合体はID順の接触ペア処理で各回1体を消し、1回の処理は開始時体数−1回以下。配列順を反転しても同じ吸収・ボーナス・由来になる。自然連鎖後の保存／復元と同seed・同配置の再実行を3seedで照合し、敵由来24個の重複・消失がないことを確認。

今後は再配置を続けた場合の攻略・長期バランス、射程拡大の分かりやすさを比較する。今回の9試行だけを根拠に倍率・時計・成長上限を変更しない。
