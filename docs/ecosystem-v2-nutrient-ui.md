# 根の吸収範囲と栄養分布の独立表示

倍率先行実装6d0643bとは別のUI変更。倍率モデル、成長、戦闘、ゲーム保存は変更しない。

表示1行目: 配置可能（配置時）/配置可能/Range/Aura/根。最後の根は各Plantの吸収円を敵味方共通で表示する。旧根runの実半径stats[root]×config.radiusPerPointを使用し、配置直後Plantは出生投影。LayerOptionsの任意rootsキーで表示設定に保存し、旧設定にキーがなければOFF。

栄養基礎行: 水分/死体/HP/Reg/Aura/根（6列）。以下のResist/属性行も土壌栄養の分布。各ボタンをmaxHp/hpReg/presence/root/各属性attack・defense・range・speedへ対応し、吸収に使う固定profileのサンプル平均比率をセル色の濃さで示す。数値や在庫を増減させない。栄養分布は水分残量そのものではなく土壌の組成比を表示。水分は従来の土壌水分量、死体は従来の死体範囲。Techは未定義のまま無効。

栄養根は既存metricFlagsのroot、各Plant根は新LayerOptions.roots。設定は独立。根runで属性ボタンを押しても個体の数値ラベルではなく栄養分布を表示する。基礎/属性の個体実数値は既存Plant詳細を維持。土壌のない通常モードでは栄養ボタンを無効にする。

ユーザーの「4行目」は栄養基礎行の意味として扱い、実UIでは表示2行目。空行を追加せず、既存の基礎・Resist・属性行を使う。寸法は1500710の通常5列/基礎6列・旧属性Stats行の実測高（PC/390で26px、320で42px）を維持。

検証: 新3tests（順序・profile対応/非干渉・根独立/設定互換）、全331tests成功、型検査と両build成功。隔離Edgeで1366×900/390×844/320×568、1行目5項目・基礎6項目・根2設定の独立・属性土壌分布・旧グリッド寸法・配置時表示・設定復元・根/通常ゲーム保存非干渉、Runtimeエラー0、横はみ出しなし。画面も確認。実機スマホではない。
