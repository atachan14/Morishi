# 将来仕様: Tier変態・累積Skill・MN/Card Cost

今回受領した将来要件の記録。現在の0基準・Tech水分処理の局所未決点に対する承認ではない。今回の範囲はdocsとDashboardへの記録のみ。本体、catalog、保存形式、バランス値は変更しない。

## 受領した要件

- パラメーターが変化した時と同時、またはその直後に種族変態を判定する。
- 種族は成長Tierを持つ。現在Tier15ならTier14以下へ変態できない。Tier16以上には変態可能で、条件を満たせばTier100等へ飛んでもよい。同Tierへの遷移は原文に指定がなく未決。
- 各種族にSkillがある。実際に変態するたびに変化先種族のSkillを追加習得し、過去に習得したSkillを累積保持する。
- Tier1→100なら、飛ばしたTier2～99のSkillは条件を満たしていても習得しない。判定に一致した候補を全て通過した扱いにしない。
- Tier1はハジマリソウ炎/氷/電/闇。初期手札は全てTier1。
- 配置力をMN（暫定名）へ変更する。MNはゲーム上限なしの大きめ整数。CardごとにCostを持ち、使用時に支払う。PlantCardでは配置時に支払う。
- 手札はSkill名でなくCard名とCostを表示する。PlantCardのCard名は種族名。
- 種族Tierと変態条件は後で調整するので仮値を使ってよい。Skillは当面既存を流用してよい。将来は種族ごとに別Skillを持たせる。

## 現行実装との差分

|領域|現行|将来の変更|
|---|---|---|
|種族|eco-v2-evolution.tsのclassifyPlant/classifyUnitがその時点の実効Stats条件を評価しpriority/idで分類。Tier・確定種族・変態履歴はない|現在種族/Tierを保持し、低Tierへ退化しない変態判定へ変更。現分類は能力低下後に低条件種族へ再分類可能であり、将来要件を満たさない|
|Skill|生成seedのkind/element/keyから習得。合体で既存Skillをキーで統合。分類が変わってもSkill追加はない|実際の変態イベントで変化先Skillだけ追加し、過去Skillを保持。飛ばした種族Skillは付与しない|
|初期手札|現在4枚、seedで属性・攻撃/治癒を生成し、能力条件から表示種族を導出|全てTier1ハジマリソウ4属性とする。4属性の初期配分、既存4枚維持の扱いは未決|
|配置力|v2のchargesは初期3・上限5。配置で1消費、8秒で1回復。撃破でも上限5まで加算|MN整数とCardごとのCostへ変更。固定消費1と上限5を置換。回復・撃破報酬の具体値は未決|
|手札表示|eco-v2-main.tsは属性＋攻撃/治癒のSkill表示|Card名＋Cost、PlantCardは種族名|
|保存|現在種族は保存せずStatsから分類。Skillは最大8の既存kind×elementキー体系|現在種族/Tier・必要な変態状態・累積Skill・MN/Costの保存と旧保存保全。Skill体系拡張時には現行の上限/キー仕様も再検討|

50種カタログ・Stats分類と画像adapterは既存成果として保持する。ただしTier付き変態状態機械と累積習得は新たな差分。全50件sprite nullであり、画像制作の未完も別に残る。固定種族が能力生成の根拠となる旧案を復活させる意味ではない。

## 未確定点

- 同Tierへの遷移可否、複数候補の選択基準。現行priority/id順や最高Tier優先を自動採用しない。
- 1回のパラメーター変化で変態を1回にするか、連鎖変態するか。判定の厳密なtick順と能力低下時の扱い。
- 合体時にどちらの種族/Tierを引き継ぐか、合体直後の変態判定、重複Skillの統合、準備時計の継承。
- 種族初期Skillの付与タイミング、重複習得の効果。既存Skill流用で同一キーになった場合の扱い。
- 手札中にも変態するか、配置時または配置後だけ判定するか。変態でCard名/Costが変わるか、未使用カードの値を固定するか。
- 初期MN、MN回復率、DrowHeist/TurnHeistとの対応、撃破報酬、各CardのCost、キャンセル/失敗配置の支払い・返金規則。
- 上限なし整数の安全な表現（Number安全整数の境界、BigInt等の保存形式）。ゲーム上の上限を黙って導入しない。
- 旧保存へのTier/MN/Cost移行と互換モード、旧原本バックアップ。

これらを仮仕様として勝手に確定しない。Tier/条件の仮値を許可されたことと、遷移/支払の未指定ルールを自由に決定することは区別する。
