# 集中吸収と配置の役割：2026-10-11 比較

## 今すぐ共有する判断

集中優位の原因は射程だけではない。全属性100%継承で、攻撃・速度・防御・射程が同時に増え、失った攻撃個体数を単体の火力が補ってしまう。最小の次の比較候補は「属性の継承25%、身体・HP・回復は100%」。同じseedで、序盤の集中突破と後半の分散攻撃に差が出た。標準を置き換えるほどの確認ではなく、明示的に新しい庭を開始する比較設定として追加した。

前後配置の攻撃位置には意味が出たが、「耐久前衛が存在感で後衛を守る」は未成立。後述の実測では初期個体への被弾が多い。25%への変更を役割設計の完成や、万能戦略の解消とは呼ばない。

## 現コードが集中を強くする仕組み

- `src/eco-contract.ts`：属性→能力は個体ごとの1対1対応。`src/eco-sim.ts` の吸収は受け手の対応を保持して、吸収相手の**属性値**を加える。相手の「速度役」そのものを引き継ぐ訳ではなく、同じ属性が受け手では「攻撃」になる場合がある。吸収後の速度・射程個性も全属性加算で埋もれる。
- 攻撃機会：ダメージは `攻撃 / (1+敵防御/70)` に距離減衰を掛ける。速度は攻撃回数/秒（上限4）。同じ能力 A・S の n体を全継承すると、上限前の単体の潜在火力は概ね n²AS、独立なら nAS。実際は成長、再対応、単一標的、距離、速度上限で変わるが、掛け算の利得がある。
- 耐久：HPと防御を共に集約し、全HPに強くなった防御が作用する。失う攻撃体数に対して耐久の見返りが大きい。回復も集約。合体は傷を残し、面積を保存して直径を `sqrt(a²+b²)` にする。
- 射程：実射程内は全威力、2倍の範囲まで減衰攻撃。全継承では別戦線への距離まで越えやすい。×5→×2だけでは、継続補給した一体の射程増大を止めなかった。
- 標的：存在感半径は実半径＋固有halo×sqrt(直径)、強さは全個体2。攻撃可能な相手の距離減衰存在感が最大の個体を狙い、同点は小さいID。全相手のスコア0ならIDが決める。前衛の防御・HPは標的選択に直接使わない。遮蔽・射線・前衛越しの攻撃遮断もないため「前だから守る」とは限らない。
- 分散の代価：各個体は独立した攻撃時計と標的を持つが、近接配置は成長して吸収する。前後の距離60は自然成長なら約17秒で接触し得る。配置時の役割がいつまでも残る訳ではない。

## 比較ルール

全案で局所射程×2、同じ生成seed・個体基礎値・手札入り時の倍率固定、実直径、接触成長、敵24体の初期全配置、停止中を含む自由配置、時計を維持。変更は**敵味方共通**の吸収継承だけ。

|設定|吸収属性値|HP・回復・身体|狙いと結果|
|---|---|---|---|
|従来（メタデータなし）|全属性100%|100%|比較基準。集中の継続補給が強い|
|quarter-v1|全属性25%|100%|能力集約の掛け算を弱め、攻撃体数を失う代価を残す。次の手動比較候補|
|guard-v1|受け手で攻撃・防御になる属性100%、速度・射程0%|100%|受け手の速度・射程を残す。今回の敵配置では進行を止めやすく、推奨標準にしない|

どちらも吸収相手の能力役をそのまま保存する方式ではない。属性対応は受け手のまま。個性を残す継承の設計は引き続き課題。

### 継続補給：序盤突破と複数戦線

開始時3枚を最初の味方に集中／初期味方3体に1枚ずつ分散。その後は使用可能なカードと配置力があるたび、集中は最大個体、分散は生存個体へ巡回して接触補給。最初は左方向、合法な16方向を探索。全滅時は全体から合法点を探す。**撃破報酬で補給枚数も変わる**ため、120秒だけを固定枚数の因果比較に使わない。

25%継承の30秒：

|seed|撃破（集中／分散）|最大防御（集中／分散）|意味|
|---|---:|---:|---|
|11|5／3|128／73|集中が局所突破を先行|
|77|5／4|120／87|集中が防御と撃破を先行、分散は生存3体対2体|
|20261011|5／4|105／95|集中が撃破を先行、分散は生存3体対2体|

25%継承の120秒（累計実攻撃。相打ちで消えた個体の最終攻撃も数える）：

|seed|補給枚数 集中／分散|撃破元敵数 集中／分散|攻撃回数 集中／分散|攻撃対象数 集中／分散|
|---|---:|---:|---:|---:|
|11|27／31|10／14|203／495|12／16|
|77|22／27|5／10|137／351|8／14|
|20261011|22／31|5／17|125／519|7／14|

同じ脚本の従来100%では集中がseed11で114.5秒、77で107秒に全24元敵を撃破し、20261011も120秒に22元敵を撃破。分散は120秒に17、16、17元敵だった。25%では後半の別方向・別対象の攻撃機会が残った。単に攻略時間が長くなったことを改善の根拠にしない。

guard-v1は120秒に集中が全seed3元敵、分散が3、5、5元敵。攻撃機会を強く抑え、射程の届かない場所と倒し切れない相手を作りやすかった。今回の値では見送る。

### 同じ3枚・追加補給なし：前後と両側

前後は最初の敵中心から `(-60,-45),(-120,-45),(-120,+45)`、両側は `(-60,-80),(-60,+80),(-130,+80)`。集中は最初の味方の直近3点、分散は各初期味方の直近1点。カード0・1・2を同じ順で使う。25%継承の30秒：

|seed|集中 撃破/攻撃/被ダメージ|分散|前後|両側|
|---|---|---|---|---|
|11|3 / 66 / 420|3 / 49 / 111|5 / 88 / 455|4 / 84 / 530|
|77|3 / 98 / 312|3 / 87 / 210|4 / 118 / 368|4 / 113 / 652|
|20261011|3 / 80 / 479|3 / 54 / 175|4 / 102 / 522|5 / 109 / 687|

前後は3seedとも集中より撃破・攻撃回数が増えるが、被弾も増える。両側はseed20261011で撃破を増やし、seed11では30秒に味方4体（集中3体）を残す。分散は初期3戦線の耐久を残して被弾を抑えるが、序盤の局所火力は下がる。配置の交換条件がある。

10秒時点は6味方がまだ独立し、前後の攻撃位置差を観察できる。seed20261011のカード0（前）の射程57.3、後方カード1は81.7、カード2は85.3で、属性→射程の対応はそれぞれ炎、電、氷。同seedの30秒時点では攻撃対象5体対集中4体。これは具体的な射程差がある例だが、カードの役割を最適選択した実験ではない。全seedで同カード番号を置いている。

### 前衛の標的誘導は残課題

前後配置の10秒までの被弾先はseed11/77でほぼ初期個体25〜27。追加の前衛28が後衛をかばっているとは言えない。seed20261011でも前衛28約9.7、後衛30約0.7の被弾があり、完全な誘導ではない。存在感の同点ID選択、初期個体への射程、halo差などを分ける必要がある。高防御・大身体＝タンクというUI説明は追加しない。

## 実装・保存・UI

`src/eco-sim.ts` に比較用の任意 `mergePolicy`。`src/eco-save.ts` は未知値・state/unit不一致を拒否。メタデータがない旧runは従来100%のまま再開し、値を後付けしない。明示的新runは従来同様に元の保存rawを退避し、失敗時の上書き防止を維持。通常の初回・新run既定は従来100%のまま。

観察Paneの「新しい庭の比較設定」に射程・吸収・seedをまとめて折りたたんだ。既存の時計調整も折りたたみ内。庭に常時追加の説明や検証数値を増やしていない。選択は新しい庭の開始にだけ適用。

検証：121テスト成功、TypeScript/Viteビルド成功。既存の旧Phaser側の大きいbundle警告は継続。隔離Edge154、1366×768／390×844で新規設定、正確な前run退避、固定手札、停止復元、再配置、観察終了、旧ページ保存維持、横溢れなしを確認。runtime error 0。`evidence/ecosystem-roles/browser/browser-check.json` とPNGに記録。スマホ画像は目視でも手札が初期画面内に収まることを確認。

## 次に判断すること

手動では同seedの25%案で「序盤集中→別戦線へ新しい独立個体」「射程が長い個体を後方へ」「短射程を近くへ」を試す。全面標準化、標的選択変更、属性ではなく能力役での継承は今回行っていない。

サンプルは3seedと固定脚本に限る。敵側の吸収も同時に変わるため、敵の弱体化と味方の役割差が混在する。最適配置、長期攻略可能性、全seedでの役割成立、万能戦略がないことは未証明。自動試遊の攻撃回数・対象数・残存個体で交換条件を見たが、面白さの判断には手動試遊が必要。

後続の標的比較では、guard案を新規UIの選択肢から外しました。保存済みguardは維持し、25%継承＋存在感同値なら距離優先の案を選べます。現時点の設定と前衛の実例は [ecosystem-targets.md](ecosystem-targets.md) を参照。
