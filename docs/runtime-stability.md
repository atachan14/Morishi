# 入力・復帰・ローカル保存の安定化

2026-10-11。開始HEAD: afa72e063d5f8548d87f8d390f1c0eb9454236d5。

## 入力と状態遷移

配置はpointerdownではなくpointerupで確定。単一のprimary/左ボタンで、500ms以内・移動8 CSS px以内・同じcanvas矩形のタップだけを受け付ける。移動して戻ったドラッグ、複数指、長押し、右クリック、pointercancel、Pane切替、resize、canvas位置変更は取り消す。敵や味方をタップした場合は選択を優先する。終了後は選択できるが配置はできない。

タブ非表示、window blur、pagehideで停止し、未消化の部分tickと入力候補を捨てる。復帰の最初のframeも捨てる。経過した背景時間をまとめて進めず、再開には時間を進めるボタンを使う。アプリ内Pane切替は入力を取り消すだけで進行を止めない。

## 保存と再現

このoriginのlocalStorage `morishi.run.v1`にseed、終了tick、速度、成功した配置と任意終了のtick付きログを保存。配置・1Tick・速度変更・終了・画面離脱時と、進行10tickごとに保存する。再読込で同じシミュレーションを再実行し、状態を復元して停止状態から再開する。部分tick、選択、カーソル位置は保存しない。

最大19操作、36000tick（ゲーム内60分）、16KBの読込制限。保存のversionはゲームルールと対応する。今後ルールを変える場合はversionを変更し、移行を検証するまで既存ログを別ルールで再生しない。上限超過・容量不足・保存権限拒否では最後の成功データを維持し、表示で知らせる。

破損・非対応versionのデータは通常の自動保存で上書きしない。明示的に新seed/入力seed/再挑戦を選んだときだけ、現在のraw保存を `morishi.run.previous.v1` に退避してから新runを保存する。退避が失敗した場合は上書きしない。バックアップは前のrunの1件で、連続した履歴保存やクラウド同期ではない。URLのhost/port変更は別の保存領域になる。
