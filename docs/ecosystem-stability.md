# 比較版の継続・待ち停止・再配置

2026-10-11。新しい能力モデルの次の保存点。既存の`/`から比較版へのリンク、比較版から旧ページへのリンクがあり、旧ルールを変換しない。

## 変更

- 味方が最後に倒れたtickの戦闘・報酬・ドロー処理を終えて、自動停止する。途中だけを保存したり余分なtickを進めたりしない。手札と合法な配置場所があれば「再配置で続けられます」と案内する。
- 「手札の候補を探す」で合法な場所へカメラを移し、候補を表示する。この操作は札も配置力も消費しない。スマホ・タッチでは能力確認後に置く。候補は勝利／安全を保証しない。マウスの配置プレビューには即時の狙い・ダメージ・自分を狙う敵数を表示する。
- 手札／配置力を待つ場合は必要なゲーム秒を表示。両方が満杯で、成長・戦闘の変化・可能な合体もない場合、時間を進めても変化しないと案内し、再生と「変化まで」を無効にする。札の配置・カメラ・観察は残す。
- 身体／敵存在感で全域が塞がる場合、空きができる戦闘・合体があり得るかを区別。証明できない細い隙間は「未特定」とし、自動敗北しない。矩形探索には4096ノード・深さ24の上限がある。
- 「今回の観察を終了」は自分で選ぶ操作。盤面・札・時計の割合を保持して停止し、再読込も終了状態のまま。旧runを消さない。
- 停止中の能力詳細を毎フレーム作り直さず、開いた詳細の操作を安定させる。PC768px高とスマホ844px高で手札が最初の画面に入るよう盤面の高さを調整。
