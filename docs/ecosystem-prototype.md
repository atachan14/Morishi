# 直径・属性対応・独立時計の比較試作

2026-10-11。就寝中も仮仕様を独断で決めてローカルGit保存しながら進める、という本人の許可に基づく比較。公開・push・課金・権限変更はしない。

## 確認済みの方向

- 炎／氷／電／闇と攻撃／防御／速度／射程は、個体ごとにシャッフルした1対1対応。属性値をもう一度能力倍率に掛けて二乗にしない。
- サイズは描画された身体の実直径。盤面内の距離・当たり判定・成長接触に同じ直径を使う。見た目を緩い曲線に圧縮しない。
- 手札入りの時点で基礎能力を固定。撃破倍率は既存手札・配置済み個体へ遡及しない。成長による現在能力の変化は続く。
- DrowHeistとTurnHeistは別の時計。スキル習得カードも将来手札に入り、配置済みユニットに使う要件。今回は植物カードのみ生成し、スキル種類・コスト・対象などは未決定。

## 今回の仮決定と理由

- 属性成長倍率は `1 + (直径 - 1) / 100`。直径1で1倍、100で1.99倍、200で2.99倍。「100で約2倍、200で約3倍」の仮解釈。HP・regenは `1 + (直径 - 1) / 80` で少し耐久寄り。
- 世界4096×3072。初期の敵24体は4群、味方3体。直径8〜20と約170の群内間隔で、成長前の余白を広く取る。
- 自然成長は毎秒直径+3、仮上限200。同陣営の接触で大きい個体が吸収。同径は小さいID。身体面積を保存し、合体後直径は `sqrt(A²+B²)`。中心・属性対応・基礎能力は吸収側を残す。
- 吸収元の現在属性、最大HP、regenを非スケールのボーナスへ一度加算。傷は保持し、新しく増えた身体のHP容量だけ加算。敵味方接触では合体せず、自然成長を止める。
- 存在感強度は全個体2で固定。半径は実身体半径＋個体のhalo×√直径。内側一定、半径外から2倍半径まで直線減衰。配置閾値は敵存在感合計1.5。身体は線形成長のまま。射程は対応属性値×5、同じ距離減衰。属性相性／粒子反応は未実装。
- 攻撃速度は対応属性値÷24、毎秒0.1〜4回。速度暴走を防ぎ、各tick最大1攻撃、ダメージは同時解決。
- 撃破した敵身体の最大属性を種別とし、そのプレイヤー属性倍率だけ+0.01。合体後の敵は身体1体として1回報酬。初期敵の由来IDを保存し、同じ敵の二重報酬を防ぐ。手札生成はtick末尾で、同tick撃破を新カードへ反映。
- ドロー4秒／配置力回復8秒。各Heistは独立。手札6枚／配置力5の満杯時はその時計だけ停止し、途中の割合を保持。満杯ドローはカード番号を消費しない。時間停止・非表示時は両方止まり、オフライン経過を追いつかせない。
- 暫定安全上限：盤面128体、直径1536、系譜4096。上限を超える合体は拒否し、身体を縮めて表示しない。自然成長200の上限と合体後サイズは別。
