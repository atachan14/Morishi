## 0基準本体接続前の確認待ち

過去の合体実効値加算のユーザー原文は親会話で確認済み。その後size全Stats乗算が廃止された最新方針を優先し、今回の新0基準形式での扱いを確認している。過去承認がなかったという意味ではない。根モードは既に実効値加算・size再乗算なし。通常percentモードには旧乗算が残る。

ユーザーへ提示済みで回答待ちの4点:

1. 成長・合体は実効値で加算して補正へ戻す。Base40ならPower40と20の合体は60→補正+50。補正0+(-100)を直接足すとPower20となり別仕様。
2. 新規初期の強さを旧実効値から変換して維持する。0近傍へ一斉に再分布しない。
3. Techは仮BaseCost1水/発動。コスト=1/M(Tech)、Tech100で0.5、200で約0.333。水不足時は準備1を保持し連射負債なし。
4. 吸水→Skill→残水で成長。

Techによる軽減・無駄撃ち消費の採用自体は承認済み。上記4点の今回の提案は承認待ちであり、本体数値・保存形式・処理順は変更していない。実効0の別状態、旧幾何互換、SkillごとのBase値、複数Skill支払順と水分mix/bonus処理も接続時に整理する。既存変換関数8tests成功。

季節と自動昼夜はモデル自体が未実装。50種は定義・Stats分類が実装済み、完成画像は全sprite null。v2のHeist倍率は旧版からの移植残り。これらは既存50種/バランス/0基準/Techタスクへ記録し、重複タスクを作らない。

## 将来のTier変態・累積Skill・MN/Card Cost

受領した新要件は [将来仕様記録](ecosystem-v2-tier-mn-future.md) を参照。パラメーター変化時/直後に変態、低Tierへ退化不可、上位Tierへの飛び可、変化先Skillのみ追加習得・累積保持。初期手札はTier1ハジマリソウ炎/氷/電/闇。配置力は上限なし整数MN（暫定名）、Card固有Costを使用時（PlantCard配置時）に支払い、手札はCard名/Cost表示。
